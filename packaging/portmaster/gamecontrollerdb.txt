# `mbn_r36s_probe --buttons` while each button was pressed in turn.

# SDL's mapping for an unlisted pad is a guess: it invents a:b0..righttrigger:b7 and
# dpup:b8..dpright:b11. On this device the d-pad is 8/11/10/9 and Select/Start are 12/13, so the
# guessed d-pad silently swallowed them: no START event ever reached the game, and the in-game
# menu (F10 / Start), the only place "Level select" and "Quit game" live, could not be opened on
# a console with no keyboard.
#
